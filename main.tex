\bluebigheading{PROPOSAL DESCRIPTION}

\vspace{6mm}

\blueheading{Motivation}

\vspace{2mm}

\answerbox{
You see lights at busy crossings to keep everyone moving smoothly. This can lead to congestion as drivers slow or stop at a red light even when few cars are coming from the opposite side. Expanding cities makes fiscally challenging to expand roadways. Urban planners and engineers must optimize the current infrastructure to achieve the most out of it. The traffic signal system should be smart enough to detect the traffic density on various roads and give priority to emergency vehicles.
}

\vspace{6mm}

\blueheading{State of the Art / Current solution}

\vspace{2mm}

\answerbox{
Most traffic lights just run on basic timers, totally oblivious to the actual line of cars waiting. Sure, some smarter lights use sensors, but they only fix traffic in their own little bubble. The latest high-tech versions even use AI and cameras to change signals on the fly. While that sounds amazing, buying and installing all that extra hardware is just too expensive for most cities. That is why the vast majority of our local lights still rely on old-school timers---and why we constantly get stuck in pointless gridlock.
}

\vspace{6mm}

\blueheading{Project Goals and Milestones}

\vspace{2mm}

\answerbox{
\textbf{General Goals}: Develop a simulation that calculates the number of cars in all lanes to estimate traffic density, changes the signal time accordingly during the simulation, and prioritizes emergency vehicles.

\vspace{2mm}

\textbf{Milestones:}

\begin{enumerate}[
    leftmargin=5mm,
    itemsep=0.5mm,
    parsep=0pt,
    topsep=1mm
]
    \item \textbf{Milestone 1:} Finish the simulation code with car arrival input and counting cars on the roads.
    \item \textbf{Milestone 2:} Finishing the algorithm that calculates the density of traffic and road occupancy.
    \item \textbf{Milestone 3:} Developing the algorithm for the signal decision using Queues, Priority Queues, and Graphs.
    \item \textbf{Milestone 4:} Creating the engine of the simulation for controlling the traffic signal at the road intersection.
    \item \textbf{Milestone 5:} Connecting all algorithms into a whole system using the C++ programming language for the test system.
    \item \textbf{Milestone 6:} Comparing the results of the system with a fixed-time system.
\end{enumerate}
}

\newpage

\blueheading{Project Approach}

\vspace{2mm}

\answerbox{
In C++, the project will be implemented using object-oriented programming and classes such as \textit{TrafficSignal}, \textit{Road}, and \textit{Vehicle}. The problem-solving techniques which will be used in the project include such data structures as:

\begin{itemize}[
    leftmargin=5mm,
    itemsep=0.7mm,
    parsep=0pt,
    topsep=1.5mm
]
    \item \textbf{Queue (FIFO):} It stores the vehicles waiting in each lane. It ensures that in each lane the vehicles enter the intersection in the same order as they queued.
    \item \textbf{Priority Queue:} It helps to decide which road to grant the signal based on the traffic density and priority, giving priority to the emergency vehicles.
    \item \textbf{Graph Structure:} It stores the roads with intersections.
    \item \textbf{Stack:} It stores the previous signal-state changes to check recent changes.
    \item \textbf{Linked List:} It stores the records of active vehicles crossing or being processed at the intersection.
    \item \textbf{Arrays \& Control Loops:} It contains the counters for the vehicles for different directions and controls the main loop of the simulation.
\end{itemize}
}

\blueheading{Assumptions}

\vspace{2mm}

\answerbox{
The project is based on several assumptions, including:
\begin{itemize}[
    leftmargin=5mm,
    itemsep=0.8mm,
    parsep=0pt,
    topsep=1.5mm
]
    \item Information on vehicle arrival and detection of emergency vehicles is retrieved from simulation modules and not actual cameras or sensors.
    \item All lanes at the intersection are assumed to have equal capacity and are cleared at approximately the same rate.
    \item Weather, traffic accidents, road construction, and pedestrian crossings are factors that are ignored for the scope of this project.
    \item The simulation uses simplified vehicle motion models and is intended to illustrate signal-control logic rather than complex vehicle dynamics.
\end{itemize}
}
