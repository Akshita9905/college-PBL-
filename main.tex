\bluebigheading{PROPOSAL DESCRIPTION}

\vspace{6mm}

\blueheading{Motivation}

\vspace{2mm}

\answerbox{
Traffic lights at intersections often use fixed-time settings to control the flow of traffic. This can cause drivers to wait at a red light even when there is little or no traffic coming from the opposite direction, which can increase vehicle idling and traffic jams. Since expanding roads in cities is difficult and expensive, engineers need to find better ways to use the existing road system. An intelligent traffic signal system is needed that can adjust its timing according to the traffic density on different roads and prioritize emergency vehicles.
}

\vspace{6mm}

\blueheading{State of the Art / Current solution}

\vspace{2mm}

\answerbox{
Most traffic lights use simple time-based settings to manage traffic without adapting to the traffic density on the roads. Some newer systems use sensors or timers to improve traffic management. These systems mainly optimize traffic at each intersection separately. Modern systems can also use video cameras and artificial intelligence for advanced traffic monitoring and can adjust signal timings dynamically.

\vspace{2mm}

Although these systems can improve traffic conditions, they require additional cameras, sensors, computing equipment, installation, and maintenance. This can make them expensive and difficult to deploy in areas with limited infrastructure. As a result, many traffic signals still use simple time-based settings, which can lead to avoidable traffic jams.
}

\vspace{6mm}

\blueheading{Project Goals and Milestones}

\vspace{2mm}

\answerbox{
\textbf{General Goals:} Create a simulation that tracks the number of cars in all lanes to determine traffic density, adjust signal timing dynamically during the simulation, and prioritize emergency vehicles.

\vspace{2mm}

\textbf{Milestones:}

\begin{enumerate}[
    leftmargin=5mm,
    itemsep=0.5mm,
    parsep=0pt,
    topsep=1mm
]

    \item \textbf{Milestone 1:} Complete the simulation code for vehicle arrival input and counting vehicles on each road.

    \item \textbf{Milestone 2:} Complete the algorithm for determining traffic density and road occupancy.

    \item \textbf{Milestone 3:} Develop the signal decision logic using Queues, Priority Queues, and Graphs.

    \item \textbf{Milestone 4:} Create the simulation engine to control the traffic signal system at an intersection.

    \item \textbf{Milestone 5:} Combine all modules using C++ to create a working test system.

    \item \textbf{Milestone 6:} Compare the results of the new system with the fixed-time system.

\end{enumerate}
}

\blueheading{Project Approach}

\vspace{2mm}

\answerbox{
The project will be implemented in C++ using object-oriented programming with classes such as \textit{TrafficSignal}, \textit{Road}, and \textit{Vehicle}. The main problem-solving techniques used in the project are data structures:

\begin{itemize}[
    leftmargin=5mm,
    itemsep=0.7mm,
    parsep=0pt,
    topsep=1.5mm
]

    \item \textbf{Queue (FIFO):} Maintains vehicles waiting in each lane. This ensures that vehicles in a lane are given access to the road in the same order in which they arrive.

    \item \textbf{Priority Queue:} Determines which road should receive the signal based on traffic density and priority, with emergency vehicles receiving higher priority.

    \item \textbf{Graph Structure:} Maintains a representation of the road network, including how different roads connect and where the intersections are located.

    \item \textbf{Stack:} Maintains previous signal-state changes so that the recent signal history can be reviewed.

    \item \textbf{Linked List:} Maintains records of vehicles currently crossing or being processed at the intersection.

    \item \textbf{Arrays \& Control Loops:} Maintain vehicle counters for different directions and control the main simulation loop.

\end{itemize}
}

\blueheading{Assumptions}
\vspace{2mm}
\answerbox{
The project is based on the following assumptions:
\begin{itemize}[
    leftmargin=5mm,
    itemsep=0.8mm,
    parsep=0pt,
    topsep=1.5mm
]

    \item Vehicle arrival information and emergency vehicle detection are provided by simulation modules and not by actual cameras or sensors.

    \item All lanes at the intersection are assumed to have similar capacity and can be cleared at approximately the same rate.

    \item The effects of weather, traffic accidents, road construction, and pedestrians crossing are ignored for the scope of this project.

    \item The simulation uses simplified vehicle movement rules and is intended to demonstrate the signal-control logic rather than represent all real-world traffic conditions.
\end{itemize}
}
